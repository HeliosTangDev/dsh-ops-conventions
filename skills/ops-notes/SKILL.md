# ops-notes — 记笔记 / 整理笔记时的规范清单

> 笔记在 `<笔记根目录>\<课程>\`。**工具会话只管工具，不改笔记内容**；跨会话时只记录需求或只做结构核对（只读）。

## 目录结构（必须保持）

```
<课程>\
├─ 00_索引.md            ← 根目录索引（列篇目与缺口）
├─ 00_课件对照.md        ← 可选：导航与叫法对照
├─ 第N章_章名\           ← 章目录必须带章名
├─ glossary\            ← 术语表 / 差异对照 / 速查
├─ mindmap\第N章_章名\   ← 思维导图，按章分目录
└─ _media\              ← 视频/音频/大图（不进笔记区）
```

- `00_` 前缀与 `_media` = **非笔记正文**；同类内容只留一份。
- 课程刚开始只有一篇时**不建章目录**，等第二篇再建。

## 文件命名

- 正文：`章.节_名称.md`
- 例题：`章.节_add_例题.md`
- 补充：`章.节_（补充）名称.md`（下划线 + 全角括号）

## 标题层级

- 篇名 `##`，节 `###`，子节 `####`，不跳级；例题篇也用 `## 篇名 例题`。

## 编码与格式

- UTF-8 **无 BOM**，行尾统一 **CRLF**（与笔记原文件一致）。
- 无 HTML `style`/`span`；不用全角空格当缩进。

## 内容红线

- 只记**问过/学过**的知识。
- 不写溯源小节、不写元描述、不放「AI 对你说的话」、不用特殊标记（※/★）。
- 交叉引用保留。

## 整理时机

- **在过程中整理**，不是事后：中间产物不落在笔记目录里，也不散落在课程根目录。
