# ops-files — 文件/目录操作清单

## 结构原则

1. **一个能力一个入口**：用户入口放根目录，实现放 `_tools\`，不为同一件事开第二个入口（教训：一天内做了 4 个"看进度"工具，最后只能合回 1 个）。
2. **加东西前先查有没有同类**：有就合并/扩展。
3. **整理在过程中做**，不是事后补。
4. 根目录只放：索引文件 + 入口 + 工具目录 + 下划线目录（`_tasks/_tools/_archive/_backups`）。

## 中间产物

- 未结束任务的中间产物 → `_tasks\<任务名>-<年月>\`；**任务一结束就删**，要留档整目录移 `_archive\` **并在归档表登记一行**。
- 一次性脚本路径用 `$PSScriptRoot`，整个任务目录才能整体搬走/删除。
- `_tools\` 只放长期复用件。

## 安全

- **删除/移动前确认解析后的绝对路径就是目标路径**（打印出来看一眼再执行），不要对计算出来的路径直接删。
- 改配置/系统设置前**先备份**；失败回滚后要 `Get-FileHash` 逐字节比对确认与备份一致，再删备份。
- 系统目录（如 `.acl-recovery\`、备份目录）别搬。

## 边界

- **工具有边界**：工具会话只动工具区；笔记/博客等别的工作区**只读**，除非用户明确授权。
- 需要写工作区外/提权时，主动申请一次放宽权限，别推给用户手动操作。

## 格式

- `.ps1`：纯 ASCII 或带 BOM 的 UTF-8（PS 5.1 按 GBK 读无 BOM 中文会静默失败）。
- `.md`/文本：UTF-8；与所在仓库既有行尾保持一致（笔记库是 CRLF）。
